# 公开与私有资料边界

## 可以公开的内容

公开文件清单包含通用代码、本文档、空白模板、测试与 examples/demo 下明确标记为虚构的资料。公开 demo.html 只能通过 --demo 从这些示例构建。

人物姓名、项目和日期全部为演示而创作，不是某位真实使用者经历的改名副本。

## 本地私人内容

真实资料放在独立的 vault/，配置放在 mylife.local.json，输出放在 dist/。仓库默认使用公开目录的允许清单；这些本地位置以及 .qa/、.release/ 均被忽略。

生成的 HTML 内含笔记全文。隐藏节点、去掉可见姓名或不在画面中展示某页，均不会自动移除其中的数据。分享真实图谱之前应单独确认内容；公开演示始终使用虚构资料。

预览服务只监听本机回环地址，只提供当前指定的一个生成页面，其他路径返回 404。它用于本地浏览，不是带账号保护的公开托管服务。

## 发布检查

```sh
node scripts/build.mjs --demo
node --test
node scripts/check-release.mjs
```

公开检查核对固定文件清单、演示虚构标记、演示输出一致性及常见凭据和本机绝对路径特征，并拒绝公开目录中的符号链接。它不能替代对新加入文字的内容判断，无法仅凭模式识别所有真实个人信息。

发布时只使用经过核对的公开文件清单。不要把整个工作目录、私人生成页、聊天记录、缓存、截图或本地 Git 配置一起上传。个人档案的访问和归属由本人控制。
